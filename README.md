# Sable & Immersive Engineering Compatibility

A compatibility addon for **Minecraft 1.21.1 (NeoForge)** that ensures **Sable** (and mods built on it, such as *Create: Aeronautics*) works together smoothly with **Immersive Engineering**.

## Features

* **Fixes Crashes:** Resolves critical server and client crashes when both mods interact.
* **Improves Stability:** Fixes world desynchronization and stability issues between the two mods.
